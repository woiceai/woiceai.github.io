# Documentation validation

The deployment source is [WoiceAI on main](https://github.com/asdkazmi/woiceai/tree/main). Run `python3 scripts/validate_docs.py` from the documentation root to check relative Markdown links, JSON examples, fenced blocks, and common secret patterns. Use the [release acceptance checklist](docs/operations/README.md) to validate a running installation.
